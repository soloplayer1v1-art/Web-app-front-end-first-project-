# Web-app-front-end-first-project-
A modern, responsive e-commerce web application built for gamers, featuring a dynamic storefront, interactive product catalog, and a fully functional shopping cart system.

FEATURES
Dynamic Product Catalog: Browse a curated collection of gaming gear, consoles, and accessories with filtering options.

Interactive Shopping Cart: Real-time item addition, quantity updates, subtotal calculations, and a seamless checkout simulation.

Responsive Layout: Optimized for seamless viewing across mobile devices, tablets, and desktop monitors.

Modern UI/UX: Dark-mode gaming aesthetic styled with clean CSS variables and subtle hover animations.

TECH STACK
HTML5: Semantic document structure and markup.

CSS3: Custom styling, Flexbox/Grid layouts, and responsive media queries.

JavaScript (ES6+): DOM manipulation, state management for the cart, and local storage handling.

GETTING STARTED

Bash
